# PaperLens · 论文可视化学习助手

把一篇论文 PDF，读成一幅地图。

上传任意论文 PDF，PaperLens 在浏览器本地自动解析论文结构（标题、摘要、章节、图表、公式、参考文献），并生成一份**可交互的可视化学习页**：阅读路线图、高频术语、概念关系图、图表速查、关键句与自测题。界面支持**中文 / English 一键切换**，可选的 AI 增强还能生成论文导读与翻译。

> 解析完全在本地浏览器中进行，论文内容不会上传到任何服务器。

## 功能

| 模块 | 说明 |
| --- | --- |
| 阅读路线图 | 按章节组织的时间线，标注预计阅读时长与章节类型（核心/背景/方法/结果），点击直达原文 |
| 高频术语 | 基于词频与分布（TF-IDF）自动提取，附首次出现的上下文例句与共现术语 |
| 概念关系图 | 术语共现关系网络（ECharts 力导向图），可拖拽探索论文的知识骨架 |
| 图表与公式 | 自动索引图、表与公式，附页码与页面缩略图 |
| 原文速览 | 按章节折叠阅读，关键句高亮，支持全文术语搜索与高亮 |
| 自测练习 | 由关键句自动生成填空与归位题，读完即练 |
| 双语言界面 | 中文 / English 界面一键切换 |
| AI 导读（可选） | 接入任意 OpenAI 兼容接口（豆包·火山方舟 / DeepSeek / OpenAI 等），生成双语 TL;DR、章节导读、概念解释与自测题 |

## 快速开始

本地运行（任选其一）：

```bash
# 方式一：Python 内置服务器
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/

# 方式二：Node
npx serve .
```

也可以直接把 `index.html` 部署到 GitHub Pages / 任意静态托管。页面上点击「试试示例论文」可立即体验（示例论文由 `tools/make_sample_pdf.py` 生成，纯虚构内容）。

## AI 导读配置（可选）

1. 点击右上角 **AI** 按钮；
2. 选择服务商（豆包·火山方舟 / OpenAI / 自定义），或填写任意 OpenAI 兼容接口的 Base URL、模型名与 API Key；
3. 点击「保存并生成导读」。

- 火山方舟：控制台创建 API Key，Base URL 形如 `https://ark.cn-beijing.volces.com/api/v3`，模型如 `doubao-seed-1.6-250615`。
- 凭据仅保存在**本机浏览器 localStorage**，代码开源可审计；AI 结果也会缓存在本地，同篇论文同语言不会重复调用。

## 技术说明

- 纯前端静态站点，单文件 `index.html`，无构建步骤，无后端；
- PDF 解析：`pdf.js`（jsDelivr CDN），文本提取与结构识别全部在浏览器本地完成；
- 图表：`ECharts`（jsDelivr CDN）；
- 术语提取：英文分词 + 中文 n-gram，TF-IDF 加权；概念图按句内共现建边；
- 关键句：位置 + 术语命中 + 长度综合打分。

## 目录结构

```
paper-lens/
├── index.html          # 全部页面、样式与逻辑（单文件应用）
├── samples/
│   ├── sample-paper.pdf  # 示例论文（虚构内容，供演示）
│   └── sample-paper.txt  # 示例论文纯文本（可读参考）
└── tools/
    └── make_sample_pdf.py  # 重新生成示例论文 PDF（纯 Python 标准库）
```

## 已知边界

- 扫描版 / 纯图片 PDF 无法提取文本，会提示「未能提取到文本」；
- 无 AI 配置时，界面语言会切换，但论文正文与摘要保持原文（不伪造翻译）；
- 图/表检测依赖编号标题（如 `Figure 1`、`表 2`），无编号的图表不会被索引；
- 论文内容较大时解析稍慢（通常在数秒内）。
